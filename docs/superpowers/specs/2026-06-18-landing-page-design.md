# XCopy 宣传页设计

- **日期**: 2026-06-18
- **产物**: 单个独立 HTML 文件(零依赖,双击即开)
- **语言**: 中文
- **视觉风格**: 浅色 + 蓝紫渐变 Hero,沿用应用 Fluent 配色

## 1. 目标

为 XCopy(Windows 剪贴板历史工具)制作一个宣传/介绍页面,以单个独立 HTML 文件形式交付。页面应能让访客在 30 秒内理解产品做什么、为什么好用,并提供明确的下载入口。

## 2. 技术形式

- **单文件 HTML**,所有 CSS 与 JS 内联,无外部资源依赖(双击 `index` 形式即可打开)。
- 图标使用内联 SVG(零图片依赖);应用 logo 用内联 SVG 或嵌入 `src-tauri/icons/128x128.png` 的 base64。
- 纯静态、零构建步骤、无运行时框架。
- 兼容主流桌面浏览器,移动端可读(响应式)。
- 放置位置:项目根目录 `landing.html`(避免与 Tauri 入口 `index.html` 冲突)。

## 3. 配色与字体

严格沿用应用本身的 Fluent 配色,确保宣传页与应用调性一致:

| 用途 | 色值 |
|------|------|
| 主色(按钮/强调) | `#0067c0` |
| 主色深(hover) | `#005aab` |
| 文本主 | `#0f172a` (slate-900) |
| 文本次 | `#64748b` (slate-500) |
| 边框 | `#e2e8f0` (slate-300) |
| 卡片背景 | `#ffffff` |
| 页面背景 | `#f8fafc` (slate-50) |
| 成功(绿) | `#107c10` |
| 危险(红) | `#c42b1c` |
| 紫色点缀 | `#8764b8` |

Hero 渐变: `#0067c0` → `#8764b8`,以柔和光晕形式铺在 Hero 顶部,主体仍为白/浅色基底。

字体: 系统无衬线栈 `-apple-system, BlinkMacSystemFont, "Segoe UI", "Microsoft YaHei", sans-serif`。

## 4. 页面结构(从上到下)

### 4.1 顶部导航栏(固定吸顶)
- 左侧: 应用 logo + "XCopy" 名称
- 右侧: 锚点链接("特性"、"预览") + 主按钮"下载"
- 半透明毛玻璃背景 + 底部细分割线

### 4.2 Hero 区
- 白底,顶部覆盖蓝紫渐变光晕(径向,低透明度)
- 主标题(大号): **"剪贴板,从未如此顺手"**
- 副标题: 一句话价值主张 —— "自动记录文本、链接与图片,按 `Ctrl+Shift+V` 即时唤起,用过就回不去。"
- 双按钮:
  - 主按钮 "下载 Windows 版" → `https://github.com/yingjunnan/XCopy/releases`
  - 次按钮:显示快捷键徽标 `Ctrl+Shift+V`(纯展示,不可点)
- 下方:用纯 HTML/CSS 绘制的应用窗口模拟卡(还原应用真实界面:圆角窗口、标题栏、分类标签、剪贴板条目),让访客直观看到产品长什么样。

### 4.3 核心特性区(4 卡片网格)
每张卡片含一个 SVG 图标 + 标题 + 一句话描述:

1. **全局快捷键唤起** — 默认 `Ctrl+Shift+V`,弹窗即用即走,失焦自动隐藏
2. **自动记录一切** — 文本、链接、图片,后台静默捕获并去重
3. **秒搜 + 分类** — 全部/文本/链接/图片 四类标签,关键词即时过滤
4. **图片预览** — 独立窗口查看大图,支持缩放与平移

### 4.4 细节亮点区(横向 2-3 条)
简短文字条目,突出工程细节:

- **轻量本地存储** — SQLite 本地存储 + 哈希去重,可自定义保留条数与天数
- **随手可配** — 开机自启、系统托盘常驻、快捷键可自定义录制
- **存储了然** — 设置面板实时显示数据库与图片各自占用的磁盘空间

### 4.5 设置面板预览区
用 CSS 还原应用的设置面板外观,展示可定制性:
- 开机自启开关
- 打开快捷键(`Ctrl+Shift+V` + 修改按钮)
- 历史保留(最多条数 / 保留天数 输入框)
- 存储占用(数据库 / 图片 两行)

此区为静态展示,不需要真实交互。

### 4.6 下载 / 页脚区
- 大号下载按钮 → `https://github.com/yingjunnan/XCopy/releases`
- 副信息:版本号 `v0.1.0`、技术栈标签(`Tauri` · `React` · `Rust` · `SQLite`)
- GitHub 仓库链接 → `https://github.com/yingjunnan/XCopy`

## 5. 交互与动效

- **滚动渐显**: 各区块进入视口时 fade-up(IntersectionObserver 实现)
- **卡片悬停**: 特性卡片 hover 时轻微上浮 + 阴影增强
- **Hero 渐变**: 顶部光晕做极缓慢的呼吸/位移动画(纯 CSS keyframes)
- **平滑滚动**: 锚点跳转用 `scroll-behavior: smooth`
- 全部基于原生 CSS/JS,无第三方库。

## 6. 响应式

- 桌面(≥900px): 特性 4 列、亮点 3 列
- 平板(600–899px): 特性 2 列、亮点 2 列
- 移动(<600px): 全部单列堆叠,导航栏按钮简化,Hero 模拟卡缩放

## 7. 文案基调

中文、简洁有力,突出"Windows 原生工具"的轻盈与顺手。避免空洞营销话术,每句话都落到具体能力。技术信息(默认快捷键、存储方式)如实呈现。

## 8. 不做的事(YAGNI)

- 不做真实下载功能(按钮外链到 GitHub Releases)
- 不做多语言切换(纯中文)
- 不做暗色模式切换
- 不做截图轮播(用 CSS 还原界面即可,零图片资源)
- 不接入分析/统计
- 不做与现有 `index.html`(Tauri 入口)的合并,独立成 `landing.html`
